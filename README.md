> **"劝人学材，...？不，这次你自己来选！"**
> 这是一款专为某大学材工学院大一新生打造的专业分流文字模拟游戏。完美适配手机端，点开即玩，带你提前体验高分子、材料物理、材料化学三大专业的硬核（秃头）生活！

---

## ✨ 游戏特色

- **🔢 真实属性初始化**：根据性别、年级、学科偏好、未来规划（保研/考研/出国/工作）等一键生成初始面板，随机精神状态（mood）与能量值，体验充满不确定性的大一生活。
- **📚 专业特色课表**：
  - **高分子专业**：材料科学基础实验、材料热力学、有机化学……
  - **材料物理专业**：固体物理与结构物性、材料物理性能、计算材料科学……
  - **材料化学专业**：物理化学、有机化学实验、催化科学与进展……
- **🎲 随机实验修仙**：随机触发硬核实验课，随机触发“实验成功（心情大好）”或“实验失败（心态爆炸）”的小游戏弹窗！
- **⚖️ 动态任务与防沉迷**：白天上课自动累积实验预习、实验报告和作业。晚上和周末可批量刷作业清零。警惕过度“谈恋爱”或“娱乐休息”，本周累计超过 5 次将触发精力反噬惩罚！
- **📊 数字化设计人视角**：通关结算时引入**马尔可夫转移矩阵**统计，以设计人视角冷酷复盘你的行为状态收束概率，并 Mock 展示群体玩家的选择倾斜。
- **📢 一键大字报**：通关后一键生成专属分流大字报，自动复制到剪贴板，方便在新生群、朋友圈互晒狂欢！

## 🛠️ 本地运行与开发

本游戏为**纯前端单文件架构**，无任何后端依赖，安全无毒，不收集任何个人隐私。

1. 下载或复制仓库中的 `index.html` 文件。
2. 双击 `index.html` 即可在电脑浏览器中本地运行。
3. 欢迎 fork 本项目，针对排课算法、数值平衡或文本彩蛋进行二次开发！
